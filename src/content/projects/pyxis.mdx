Frustrated by how slow some apps are when I want to access them with bad internet, I built Pyxis, because "todo list" was a common project for first-timers, right?

Pyxis relies on flat text files as the source of truth, reducing sync conflicts by only deriving certain properties when necessary. Pyxis currently indexes in 47ms with 290 files, because it's an early prototype architecture for what [[proj!Horologium]] optimized later.
